# Exporta spec — propagar comando/skill a proyectos OpenSpec

> **Command:** `.claude/commands/exporta-spec.md`  
> **Skill:** `.claude/skills/exporta-spec/SKILL.md`  
> **Script:** `<ai-developer>/scripts/exporta-spec.sh`

Propagates Claude Code infrastructure (command `.md`, skill folder — rules are folded into the skill's `SKILL.md`, no separate rule file) from the **source repo** to every OpenSpec project discovered under the developer's **projects base directory** (parent of `htdocs/`).

---

## Phase 0 — Parse human intent

Extract from the message:

| Field | Examples |
|-------|----------|
| **Slug** | `html`, `comando-verificar`, `gaps-spec`, `exporta-spec`, `repasa-spec` |
| **Type** | `command`, `skill`, `bundle` (optional — default `bundle`) |
| **Scope** | `all`, `todos` → deploy every bundle under `templates/openspec-claude/*/bundle.manifest` |
| **PROJECTS_BASE** | env `PROJECTS_BASE=…`, legacy `HTDOCS_BASE=…`, or default |

**Slug normalization:** lowercase, hyphens; strip leading `/` from command names (`/html` → `html`).

When the developer asks to export **everything** (all spec commands/skills including `exporta-spec` itself):

```bash
bash "${AI_DEV}/scripts/exporta-spec.sh" --all --projects-base "${PROJECTS_BASE}"
```

---

## Phase 1 — Resolve paths

### Source repo

```bash
SOURCE_ROOT="$(git rev-parse --show-toplevel)"
```

### Projects base (mandatory check)

Default scans from the **parent directory** (includes `htdocs/` and sibling repos):

```bash
PROJECTS_BASE="${PROJECTS_BASE:-${HTDOCS_BASE:-$HOME/projects}}"
if [[ ! -d "${PROJECTS_BASE}" ]]; then
  # STOP — AskQuestion: "¿Cuál es la ruta base de tus proyectos?"
  # Re-run with: exporta-spec.sh --slug … --projects-base "<answer>"
fi
```

Legacy alias: `--htdocs-base` and env `HTDOCS_BASE` still work.

### Projects registry (local-only — never commit)

After discovery/deploy the script writes:

| File | Path |
|------|------|
| JSON registry | `<PROJECTS_BASE>/.claude-local/export-spec/projects-registry.json` |
| Markdown list | `<PROJECTS_BASE>/.claude-local/export-spec/projects-registry.md` |
| Per-repo mirror (gitignored) | `<each-project>/.claude/context/export-spec/projects-registry.json` |

**Prohibited:** commit registry files. They live under `.claude-local/` (outside git) or `.claude/context/` (gitignored in product repos).

### ai-developer (canonical bundle store)

Try in order until `scripts/exporta-spec.sh` exists:

```bash
AI_DEV=""
for candidate in \
  "${PROJECTS_BASE}/htdocs/ai-developer" \
  "${PROJECTS_BASE}/ai-developer" \
  "$(dirname "${SOURCE_ROOT}")/../ai-developer" \
  "$(dirname "${SOURCE_ROOT}")/ai-developer"; do
  resolved="$(cd "${candidate}" 2>/dev/null && pwd)" || continue
  if [[ -f "${resolved}/scripts/exporta-spec.sh" ]]; then
    AI_DEV="${resolved}"
    break
  fi
done
```

If not found → **STOP**; report that `ai-developer` clone is required.

---

## Phase 2 — Discover artifact files (source repo)

### By type

| Type | Source path(s) |
|------|----------------|
| **command** | `.claude/commands/<slug>.md` |
| **skill** | `.claude/skills/<skill-dir>/` — at minimum `SKILL.md`; include sibling `*.md` in same folder |
| **bundle** | All related files for slug (see heuristics below) |

### Bundle heuristics (type omitted or `bundle`)

For slug `S`, collect existing files:

| Pattern | Path |
|---------|------|
| Command | `.claude/commands/${S}.md` |
| Skill dir | `.claude/skills/${S}/SKILL.md` |
| Alt skill names | `.claude/skills/openspec-gap-analysis/` when `S=gaps-spec`; grep `name: ${S}` in skill frontmatter |

**Extra paths:** if command/skill mentions `docs/openspec/`, `openspec/specs/`, copy those paths too into bundle preserving relative layout.

**Validate:** at least **one** file must exist or **STOP** with list of paths tried.

---

## Phase 3 — Build bundle

Target directory:

```text
${AI_DEV}/templates/openspec-claude/<slug>/
```

### bundle.manifest format

One deploy mapping per line: `src_in_bundle=dest_in_project`

```text
# bundle.manifest — generated by /exporta-spec
html.md=.claude/commands/html.md
SKILL.md=.claude/skills/html/SKILL.md
# optional universal copy for link-ai-developer:
universal:SKILL.md=html/SKILL.md
```

Rules:

- Left side: path relative to bundle root (use subdirs if needed: `docs/foo.md=docs/foo.md`).
- Lines starting with `#` ignored.
- `universal:` prefix copies to `ai-developer/skills/universal/` (not to each project).

### Copy files

```bash
BUNDLE="${AI_DEV}/templates/openspec-claude/${SLUG}"
mkdir -p "${BUNDLE}"
# cp each source → bundle using manifest left-hand names
```

### README.md (if missing)

```markdown
# <slug> — OpenSpec Claude Code bundle

Exported from: <SOURCE_ROOT>
Deploy: bash ai-developer/scripts/exporta-spec.sh --slug <slug>
Deploy all: bash ai-developer/scripts/exporta-spec.sh --all
```

---

## Phase 4 — Deploy (smart update)

Default: **compare before copy**. For each manifest entry in each target project:

| State | Script action |
|-------|---------------|
| Destination missing | `NEW` — copy from bundle |
| Exists, `cmp` differs | `UPDATE` — overwrite |
| Exists, `cmp` identical | `SKIP` (unchanged) — no write |
| `--force` | `FORCE` — always overwrite |

Project-level: `SKIP project (all files unchanged)` when every mapped file matches the bundle.

```bash
bash "${AI_DEV}/scripts/exporta-spec.sh" --slug "${SLUG}" --projects-base "${PROJECTS_BASE}"
```

**All bundles** (includes `exporta-spec`, `repasa-spec`, `gaps-spec`, `html`, …):

```bash
bash "${AI_DEV}/scripts/exporta-spec.sh" --all --projects-base "${PROJECTS_BASE}"
```

**Dry-run** when human says `simular` / `dry-run`:

```bash
bash "${AI_DEV}/scripts/exporta-spec.sh" --slug "${SLUG}" --projects-base "${PROJECTS_BASE}" --dry-run
```

**Force full re-copy** only when developer explicitly requests it:

```bash
bash "${AI_DEV}/scripts/exporta-spec.sh" --slug "${SLUG}" --projects-base "${PROJECTS_BASE}" --force
```

### Exit handling

| Exit | Action |
|------|--------|
| `0` | Parse `discovered=N` and `## EXPORT_STATS`; **paste all `TARGET:` lines** under `## Directorios exportados`; mention `REGISTRY=` path |
| `1` | Show stderr; fix manifest/files |
| `2` | Ask for `PROJECTS_BASE`; do not proceed until answered |

---

## Phase 5 — Optional post-patches

When exporting a **new** bundle (first time), append to **source** repo docs (not auto-patched in targets — agent may do per project if asked):

- `.claude/skills/README.md` — table row for skill/command

Use `grep` to avoid duplicate entries.

---

## Phase 6 — Reply (mandatory directory list)

The script **always** prints a machine-readable block at the end:

```text
## EXPORT_TARGETS
PROJECTS_BASE=$HOME/projects
REGISTRY=$HOME/projects/.claude-local/export-spec/projects-registry.json
SLUG=html
COUNT=12
TARGET:/path/to/project-a
TARGET:/path/to/project-b
…
```

**Always** include in the chat message:

```markdown
## Directorios exportados

- **Base:** `<PROJECTS_BASE>`
- **Registro (local):** `<REGISTRY>` — no versionar
- **Slug:** `<slug>` or `all`
- **Total:** N proyectos

1. `/path/to/project-a`
2. `/path/to/project-b`
…
```

Copy every `TARGET:` path from script stdout (sorted as emitted). Applies to **real deploy and `--dry-run`**.

```markdown
## Estadísticas de despliegue

- **Nuevos:** FILES_NEW
- **Actualizados:** FILES_UPDATED
- **Sin cambios:** FILES_UNCHANGED
- **Proyectos tocados:** PROJECTS_TOUCHED
- **Proyectos sin cambios:** PROJECTS_UNCHANGED

## Verification
- **Verified:** `exporta-spec.sh --slug <slug> --projects-base <path>` exit 0; stdout `discovered=N` + `COUNT=N` in `## EXPORT_TARGETS` + `## EXPORT_STATS`
- **Verified:** bundle at `<AI_DEV>/templates/openspec-claude/<slug>/bundle.manifest` (M files)
- **Verified:** registry at `<PROJECTS_BASE>/.claude-local/export-spec/projects-registry.json`

## Resumen
- Exportado `<slug>`: N proyectos revisados; X archivos nuevos, Y actualizados, Z sin cambios; listado completo en **Directorios exportados**.
```

## Examples

### Full bundle

```
/exporta-spec html
```

→ Bundle `html` with command + skill → all OpenSpec targets under `$PROJECTS_BASE`.

### Export all spec bundles

```
/exporta-spec all
```

→ Every `templates/openspec-claude/*/bundle.manifest` including `exporta-spec` itself.

### Command only

```
/exporta-spec command verifica-cierra
```

→ Single line in manifest: `verifica-cierra.md=.claude/commands/verifica-cierra.md`

### Re-sync existing bundle

```
/exporta-spec bundle html
```

→ Skip Phase 2 discovery; run script only (manifest must exist).

### Custom base

```
/exporta-spec html
PROJECTS_BASE=/data/projects
```

---

## Anti-patterns — forbidden

1. Deploy without writing `bundle.manifest` first.
2. Invent `PROJECTS_BASE` when default path is missing.
3. Export to non-OpenSpec dirs manually (use discovery script only).
4. Skip verification of script exit code.
5. **Commit** `projects-registry.json` or `.claude/context/export-spec/` mirrors.

---

## Self-export

To propagate `/exporta-spec` itself (or everything at once):

```bash
bash ai-developer/scripts/exporta-spec.sh --all --projects-base "$PROJECTS_BASE"
```
